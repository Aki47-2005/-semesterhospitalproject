# HOSPITAL MANAGEMENT SYSTEM

## 1. Project Description
The Hospital Management System is a web-based application developed to help hospitals manage patient information and hospital activities electronically.

## 2. Project Objectives
- To register and manage patients.
- To store patient records.
- To manage hospital information.
- To reduce paperwork.
- To improve information storage and retrieval.

## 3. Technologies Used
- Python
- Django Framework
- HTML
- CSS
- JavaScript
- SQLite Database

## 4. System Features
- Patient Registration
- Patient Records Management
- Patient Information Updating
- Patient Information Deletion
- Viewing Patient Records

## 5. Project Structure
- models.py - Defines database models.
- forms.py - Handles user input forms.
- views.py - Handles application logic.
- urls.py - Defines application URLs.
- templates/ - Stores HTML files.

## 6. How to Run the Project

1. Open the project in VS Code.
2. Activate the virtual environment.
3. Run the command:

python manage.py runserver

4. Open the browser and visit:

http://127.0.0.1:8000/
